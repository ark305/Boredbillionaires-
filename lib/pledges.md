# Demo pledge storage contract

This is for the dashboard, leaderboard and chat builders. Pledges are demo only: no database, no payments, no money moves.

## Where pledges are stored

- **Storage:** `localStorage`, browser only.
- **Key:** `bored-billionaires:pledges:v1`, exported as `PLEDGES_STORAGE_KEY` from `lib/pledges.ts`.
- **Value:** a JSON array of `Pledge`, oldest first. Each new confirmed pledge is appended, and entries are de-duplicated by `id`.

## Pledge shape

```ts
type Pledge = {
  id: string;              // crypto.randomUUID(), generated by POST /api/pledges
  projectId: string;       // matches data/catalog.json projects[].id
  amountUSD: number;       // > 0, at most 2 decimals, validated against the catalog
  outcome: string;         // exact catalog outcome text, in the donor's language at pledge time
  donorName: string;       // trimmed; "Anonymous" when left blank
  donorIntent: string | null; // optional "why this project", max 280 chars
  createdAt: string;       // ISO 8601 timestamp, e.g. "2026-11-07T18:30:00.000Z"
  demo: true;              // always true
};
```

Example:

```json
[
  {
    "id": "1f103f64-9202-4fbc-80d7-c8dfdd54dd76",
    "projectId": "miami-coral-restoration",
    "amountUSD": 250,
    "outcome": "Plants 10 coral fragments on the reef",
    "donorName": "Anonymous",
    "donorIntent": null,
    "createdAt": "2026-11-07T19:07:25.019Z",
    "demo": true
  }
]
```

How `outcome` is chosen: a fixed price point gets that price point's `outcome[locale]`. A custom amount on an open-amount project gets `openAmount.outcome[locale]`. `outcome` is stored as display text. To re-localize it, look up the project in `data/catalog.json` with `projectId` and `amountUSD`.

## Reading pledges

```ts
import { readPledges, PLEDGES_UPDATED_EVENT, PLEDGES_STORAGE_KEY } from "@/lib/pledges";

const pledges = readPledges(); // Pledge[], ignores malformed entries, [] on the server or on error

// Same tab: fired after each confirmed pledge (event.detail is the new Pledge)
window.addEventListener(PLEDGES_UPDATED_EVENT, () => setPledges(readPledges()));
// Other tabs: the native storage event
window.addEventListener("storage", (e) => {
  if (e.key === PLEDGES_STORAGE_KEY) setPledges(readPledges());
});
```

Call `readPledges()` in an effect (client only), never during server render.

## API

`POST /api/pledges`

Request body:

```json
{ "projectId": "clean-water-wells", "amountUSD": 37.5, "donorName": "Felipe", "donorIntent": "water access", "locale": "en" }
```

| Response | Body |
| --- | --- |
| `201` | `{ pledge: Pledge }` |
| `400` | `{ error: "invalid_json" }` |
| `404` | `{ error: "project_not_found" }` |
| `422` | `{ error: "invalid_amount" \| "amount_not_offered" \| "below_minimum" \| "above_maximum" \| "invalid_donor_name" \| "invalid_donor_intent" }` |

Every error body also includes `demo: true`.

The server stores nothing. The client saves the returned pledge with `savePledge()`.

## Integration URL

`/pledge?projectId=<id>`. You can also pass `&intent=<text>` to prefill `donorIntent`, for example the phrase a chat match was based on. An unknown or missing `projectId` shows a project picker.
